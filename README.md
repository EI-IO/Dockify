# Dockify · 一键变 Dock

> 给 Windows 11 任务栏做**两侧裁切 + 圆角**，一键把「开始按钮 + 程序图标 + 系统托盘」压成一条**居中的悬浮 Dock**。

> 给 Windows 11 任务栏做**两侧裁切 + 圆角**，并支持把「开始按钮 + 程序图标 + 系统托盘」压成一条**居中的悬浮 Dock**。
>
> A tiny tray app for Windows 11: rounds the taskbar corners, crops its two ends, and can turn the taskbar into a centered floating dock.
> **No installer, no runtime, no injection** — a single ~60 KB `.exe` built with the `csc.exe` that ships with Windows.

## 功能

- **两侧裁切 + 圆角**（默认模式）：任务栏不再贴屏幕左右边缘，四角变圆角，中间仍是系统原本的任务栏。
- **紧凑 Dock**：把任务栏重排成一条居中的圆角短条 —— 开始按钮、程序图标、系统托盘连成一排，长度随图标增减自动伸缩。
- **托盘弹出面板跟随**：`^` 隐藏图标面板跟着托盘一起平移（毫秒级、一步到位，不会"先弹错位置再跳一下"）。
- **自动隐藏兼容**：任务栏窗口本身从不移动，滑出/唤出与点击行为完全不受影响。
- **托盘常驻**：右键可开设置、切换模式、开关开机自启、恢复任务栏原样。
- **纯文本配置**：所有可调项都在一个带注释的 `.ini` 里，可直接手改。

## 快速开始

1. 下载 Release 里的 `Dockify-v1.0.zip`，解压到任意目录（例如 `D:\Tools\Dockify\`）。
2. **双击 `Dockify.exe`**（**不要在受限的终端 / 沙箱里启动**，见"常见问题"）。
3. 首次启动会自动生成配置文件并弹出设置窗口。
4. 托盘出现图标 → 右键可随时调整。

**想还原任务栏**：双击 `reset-taskbar.cmd`，或托盘右键 →「恢复任务栏原样」。

## 使用

### 托盘图标右键菜单

| 菜单项 | 说明 |
|---|---|
| 启用 / 暂停 | 临时停用（暂停会立刻把任务栏还原） |
| 模式 → 裁两端 | 整屏宽，只把两头裁圆 |
| 模式 → 紧凑 Dock | 图标 + 托盘压成一条居中的短条 |
| 设置 | 打开设置窗口 |
| 开机自动启动 | 写入启动项 |
| 恢复任务栏原样 | 等于 `--reset` |

### 命令行

```bat
Dockify.exe                :: 常驻 + 托盘（首次运行会弹设置窗口）
Dockify.exe --settings     :: 直接打开设置窗口
Dockify.exe --apply        :: 只套用一次就退出（退出码 0=成功 2=失败，便于脚本/计划任务）
Dockify.exe --diag         :: 跑一遍并把过程写到 diag.txt
Dockify.exe --reset        :: 一键还原任务栏（内容区、托盘、裁切全部还原）
```

## 设置项一览

> **所有尺寸类选项都是「占屏幕尺寸的浮点百分比」**（两位小数）。
> **横向项**按屏幕宽度算，**纵向项**按屏幕高度算 —— 换分辨率、换 DPI、换显示器都不用重调。

| 设置 | 单位 | 范围 | 说明 |
|---|---|---|---|
| 启用 | 勾选 | | 取消勾选立刻还原任务栏 |
| 模式 | 单选 | | `裁两端` / `紧凑 Dock` |
| **圆角圆度** | %（屏高） | 0 ~ 6 | 12px @1080p ≈ **1.11%** |
| **左裁切 / 右裁切** | %（屏宽） | 0 ~ 20 | 「裁两端」模式的两侧裁掉多少 |
| **短条留白** | %（屏宽） | 0 ~ 10 | 短条比内容每边多留的白；27px ≈ **1.4%** |
| **图标/托盘间距** | %（屏宽） | 0 ~ 5 | 程序图标区与系统托盘之间的空隙；16px ≈ **0.83%** |
| **内容长度微调** | %（屏宽） | 0 ~ 20 | 把内容区往窄了收（托盘会更往左靠）；20px ≈ **1.04%** |
| **左侧裁切微调** | %（屏宽） | −30 ~ 20 | **负值 = 往右多裁、贴近 Windows 图标**；−30px ≈ **−1.56%** |
| 上边距 / 下边距 | %（屏高） | 0 ~ 6 | 在「更多设置」里 |
| ^面板左移 | %（屏宽） | 0 ~ 50 | `^` 隐藏图标面板额外左移多少；150px ≈ **7.8%** |
| 所有显示器都处理 | 勾选 | | 副屏任务栏一起处理 |
| 数值随系统缩放 | 勾选 | | 内部常量是否跟随 DPI |
| 任务栏自动隐藏时也处理 | 勾选 | | 默认开 |

**换算方法**：`百分比 = 像素 ÷ 屏幕尺寸 × 100`
例：1080p（1920×1080）上想要 30px 的左侧裁切 → `30 ÷ 1920 × 100 = 1.56%`

## 配置文件

路径：`%APPDATA%\Dockify\settings.ini`（纯文本，UTF-8，带注释，可直接编辑）

```ini
Enabled=1
Radius=1.11              # 圆角圆度 %（屏高）
MarginLeft=0.42          # 左裁切 %（屏宽）
MarginRight=0.42         # 右裁切 %（屏宽）
MarginTop=0              # 上边距 %（屏高）
MarginBottom=0           # 下边距 %（屏高）
Mode=2                   # 0 = 只裁两端, 2 = 紧凑 Dock
DockPadding=1.4          # 短条留白 %
ClusterGap=0.83          # 图标/托盘间距 %
DockWidthTrim=1.04       # 内容长度微调 %
DockOffsetX=-1.56        # 左侧裁切微调 %（负 = 贴近 Windows 图标）
FlyoutOffsetX=7.81       # ^面板左移 %
AllMonitors=1
ScaleWithDpi=1
ApplyOnAutoHide=1
```

- **首次启动**：文件不存在时自动写入默认值（并弹出设置窗口）。
- **之后每次启动**：完全从文件读取，不用默认值覆盖。
- **老版本配置**：按 `SettingsVersion` 自动迁移（像素 → 百分比）。
- 万一写不进去，原因会记在 `%APPDATA%\Dockify\diag.txt` 的 `配置写入失败:` 一行。

## 构建

**不需要 Visual Studio，也不需要 .NET SDK** —— 用 Windows 自带的 `csc.exe` 即可。

```bat
:: 方式一：双击
build.cmd

:: 方式二：PowerShell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1

:: 产物
dist\Dockify.exe
```

`build.ps1` 做这几件事：

1. 定位 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`
2. 若 `build\app.ico` 不存在则现场生成（纯代码画图标，无外部素材）
3. 先删掉旧的 `dist\Dockify.exe`（避免编译失败却留下旧产物）
4. 编译 `src\Dockify.cs`，引用 `System.Windows.Forms` / `System.Drawing` / `UIAutomationClient` / `UIAutomationTypes` / `WindowsBase`

### 源码结构

单文件 C#，**C# 5 语法**（系统自带 csc 不支持更高版本，所以没有字符串插值 / `?.` / `nameof`）：

| 部分 | 作用 |
|---|---|
| `Native` | 全部 P/Invoke（窗口、区域、UIA、注册表等） |
| `Settings` | 配置读写、版本迁移、范围裁剪 |
| `TaskbarEngine` | 核心：测量 → 计算 → 套区域 / 摆内容区 / 移托盘 |
| `SettingsForm` | 设置窗口（含百分比滑块控件） |
| `HiddenWindow` | 收系统消息（注销、关机、分辨率变化） |
| `Program` | 单实例、托盘图标与菜单、命令行、自检与还原 |

## 工作原理（都是实测结论）

1. **任务栏是 Explorer 的顶层窗口**（主屏 `Shell_TrayWnd`、副屏 `Shell_SecondaryTrayWnd`）。
   用 `SetWindowRgn` + `CreateRoundRectRgn` 给它一个圆角矩形区域即可裁切 —— 窗口区域不影响布局，
   所以任务栏窗口本身**从不移动**，自动隐藏 / 唤出行为完全不受影响。

2. **任务栏画面由子窗口承载**：`Windows.UI.Composition.DesktopWindowContentBridge`（内容区）。
   改它的**宽度**会让 Windows 重排任务栏内容：程序图标组位置不变，而**系统托盘贴到内容区右端**。
   于是「内容区右端 = 图标右端 + 间距 + 托盘宽」就能让托盘紧贴图标，且**增删图标时自动伸缩**。

3. **可见的短条形状由内容区决定**，窗口区域只能"切"、不能"补"。
   所以**区域边界必须落在内容里侧**，两侧圆角才会显现（内容区右端要比托盘再宽一点点）。

4. **UI Automation 的图标矩形比可见图标宽一圈**（开始按钮有内边距）。
   「左侧裁切微调」就是在补偿这段差值（1080p @125% 实测约 47px），否则短条会离图标一段空隙。

5. **UI Automation 只在任务栏"唤出"时才有按钮**：自动隐藏滑出屏幕时返回空树。
   程序因此在任务栏不在屏幕内时**整轮跳过**（绝不用过期数据推算 —— 早期版本正是这样越推越偏）。

6. **平移内容区是危险的**：曾尝试"平移内容区让整组居中"，但宽度公式含 `-relX`，
   一左移宽度就跟着膨胀，撞上"整条任务栏宽"后 Windows 按整屏重排、短条报废。
   现在宽度**与位置完全解耦**，并设了硬上限（绝不允许等于整条任务栏宽）。

7. **托盘弹出面板**：`^` 隐藏图标面板（`TopLevelWindowForOverflowXamlIsland`）跟着托盘锚定，
   用 `SetWinEventHook(EVENT_OBJECT_SHOW / EVENT_OBJECT_LOCATIONCHANGE)` 在它出现的**毫秒级**摆好位置；
   网络 / 音量 / 电池 的快捷设置（`Xaml_WindowedPopupClass`）本身锚定正常，**不移动**。

## 已知限制

- **圆角是硬边**：窗口区域是 1 位掩码，无法抗锯齿。想要真正平滑的圆角需要注入 Explorer（Windhawk 等方案）。
- **内容区收得太窄时 Windows 会开始隐藏图标**（它的保护机制），不是程序隐藏的。
- **任务栏"居左"对齐时紧凑 Dock 不成立**（图标组钉在最左边），程序会自动退回"裁两端"并在状态栏说明。
- **必须从正常桌面启动**：若从受限终端 / 沙箱里被拉起，进程拿不到干净上下文，会看不到任务栏
  （诊断里表现为 `任务栏: 找到 0 个`）。程序会尝试**请资源管理器代为重启一次**；
  仍不行就**以管理员身份运行**，或重启一次资源管理器。
- **Explorer 更新可能改变几何**：内容区子窗口类名、按钮内边距等若变化，需按"工作原理"第 4 条重新校准。
- 仅主屏 + 副屏任务栏做了处理；竖排任务栏未测试。

## 常见问题

**Q：短条出来了，但左边空一块？**
A：那是"开始按钮矩形"与"可见图标"的差值。把「左侧裁切微调」往负方向调，直到短条贴住图标
（1080p @125% 参考值 `-1.56%`；调过头会切进图标，回调一点即可）。

**Q：状态栏显示"未找到任务栏"？**
A：进程上下文受限。退出后**从文件资源管理器双击**启动；或右键 →「以管理员身份运行」；
或先重启一次「Windows 资源管理器」。

**Q：任务栏一直闪 / 在两个模式间跳？**
A：早期版本的 bug（"居左"误判 + 失败无冷却），已修复。若仍出现，看一眼设置窗口状态行的说明。

**Q：想彻底卸载？**
A：`--reset` 还原任务栏 → 删除程序目录与 `%APPDATA%\Dockify\` → 删除开机自启项即可。
